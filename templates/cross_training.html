What these terms actually mean

Trained / Not Trained

Comes straight from the uploaded hours-on-function export's "Trained Status" column — this app doesn't calculate it from hours or apply any threshold of its own. Whatever the source system says (Trained or Not Trained) is what shows here, unchanged.

Proficiency status (Proficient / Practice / Refresh / Lapsed)

Imported directly from the "Proficiency Status" column — this app doesn't decide which tier someone is in, that determination is made upstream. The actual upstream logic, a cascading check from the most recent window down:

ifelse(
    {Total_Hours_60} >= 20, "Proficient",
    {Total_Hours_90} >= 20, "Practice",
    {Total_Hours_180} >= 20, "Refresh",
    "Lapsed"
)

In plain terms: 20+ hours within the last 60 days is Proficient; falling short of that but still 20+ within 90 days is Practice; falling short of that but still 20+ somewhere within 180 days is Refresh; under 20 hours across the whole 180-day window is Lapsed. Because Practice is checked against the shorter (90-day) window and Refresh against the longer (180-day) one, Practice is the more-current state of the two, despite what the label alone suggests. What this app does define is the score each tier is worth on the Cross-Training Compliance scorecard, matching that same order:

  • Proficient = 100 points — 20+ hours within the last 60 days.
  • Practice = 60 points — 20+ hours within the last 90 days, but not 60.
  • Refresh = 30 points — 20+ hours within the last 180 days, but not 90.
  • Lapsed = 0 points — under 20 hours across the full 180-day window.

The Cross-Training Score shown elsewhere is the average of these points across every record in scope.

Becoming Lapsed — the "Lapsing in X days" / Retention projections

This is something this app calculates, from the "last date on process" column: projected Lapsed date = last date on process + {{ xt_proficiency_expiry_days }} days. It's a single uniform countdown applied the same way to anyone not already Lapsed (Proficient, Practice, or Refresh) — there's no separate per-tier timer, so it always means "days until this person is projected to become fully Lapsed on this process," never "days until they drop one step down." This day count itself isn't a value LDIS has an authoritative source for — it's currently {{ xt_proficiency_expiry_days }} days as a placeholder.

Ambassador hours threshold

Separate from the above, and specific to the Ambassador Hours/Readiness features (not general Cross-Training): every tracked ambassador process uses the same flat 20-hour standard (last 60 days) — an ambassador below 20 hours on any of their department's tracked processes is flagged as needing more practice.

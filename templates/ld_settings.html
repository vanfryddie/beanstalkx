Auto-detect roles from job titles

Scans job titles from the compliance data (most usefully Safety Training Compliance, which is the only import that carries a title) — Area Manager, Operations Manager (non-senior), Senior Operations Manager, Trainer, Team Lead, and Learning Manager titles are all matched directly, with any variant wording (Interim, L5, Sr, Snr, etc.) recognized. Area Manager → Operations Manager and Operations Manager → Senior Operations Manager reporting lines are then wired up automatically using each person's supervisor login. Safe to run again after new data comes in — it never overwrites a role someone already has, only fills in title and reporting line.

{#- Charts, hand-built in SVG. The console carries no front-end dependencies and this is not the reason to start. Every macro here renders server-side markup; the only script is one shared crosshair for the time series. Colours come from the validated two-slot categorical palette and the blue sequential ramp, declared once in style.css as --viz-* tokens so light and dark swap in one place. Two series is the ceiling here by design: everything on these pages is either one magnitude over time, or a home/away split. -#} {% macro sparkline(values, width=104, height=28, positive_is_good=true) -%} {#- A trend inside a stat tile: no axes, no labels, no tooltip. It says "this shape", and the figure beside it says the number. -#} {%- set clean = values | reject('none') | list -%} {%- if clean | length > 1 -%} {%- set lo = clean | min %}{% set hi = clean | max -%} {%- set span = (hi - lo) if (hi - lo) else 1 -%} {%- set step = (width - 4) / ((clean | length) - 1) -%} {%- set pts = [] -%} {%- for v in clean -%} {%- set _ = pts.append('%.1f,%.1f' % (2 + loop.index0 * step, height - 3 - ((v - lo) / span) * (height - 6))) -%} {%- endfor -%} {%- endif -%} {%- endmacro %} {% macro stat(label, value, sub=None, series=None, tone=None) -%}
{{ label }}
{{ value }} {% if series %}{{ sparkline(series) }}{% endif %}
{% if sub %}{{ sub }}{% endif %}
{%- endmacro %} {% macro area_chart(title, points, unit='', height=150, fmt='{:,.0f}') -%} {#- One magnitude over time. The crosshair does the rest. -#} {%- set clean = points | selectattr('value', 'defined') | rejectattr('value', 'none') | list -%} {%- endmacro %} {% macro diverging_bars(title, rows, caption=None, limit=12) -%} {#- Delta to target: above and below one baseline, which is the one thing a plain bar chart cannot show. Over and under get the two categorical hues rather than green and red, because green and red are reserved for status and this is a measurement. -#} {%- set shown = rows[:limit] -%} {%- set widest = ((shown | map(attribute='value') | map('abs') | max) or 1) if shown else 1 -%} {%- endmacro %} {% macro meter(value, limit=100, label=None, unit='%', good_at=95) -%} {#- One ratio against a limit.

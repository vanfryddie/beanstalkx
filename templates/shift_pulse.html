The data provider isn't running

Shift Pulse reads FCLM through your own browser session, so this page stays empty until the provider userscript is installed and running on it. The server cannot fetch FCLM on your behalf — it has no Midway session, and it shouldn't have one.

  1. Install the Tampermonkey extension (Chrome, Edge or Firefox).
  2. Install Shift Pulse — Data Provider from this console. It is the standard provider with its @match pointed here instead of at a local file.
  3. Make sure your Midway session is current, then reload this page.

Questions, problems or ideas go to your Site Process Engineer, same as the standalone tool — this is the same dashboard, hosted.
